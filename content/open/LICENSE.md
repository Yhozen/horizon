# Licence of `content/open/`

The root MIT licence does not cover the media in this folder. Each file under `media/` keeps the
licence of its author, recorded for that file in [`sources.json`](sources.json) (`license`, with
its `author` and `origin`). The licence texts are in [`licenses/`](licenses/):

- `CC-BY-SA-3.0`: Creative Commons Attribution-ShareAlike 3.0 Unported
- `CC-BY-SA-4.0`: Creative Commons Attribution-ShareAlike 4.0 International
- `CC0-1.0`: Creative Commons CC0 1.0 Universal

`notices/` holds the upstream projects' own licence and credit files, unchanged. `licenses/` holds
the official Creative Commons texts.

The Horizon Open bundle built from this folder (`horizon-prepare open`) is distributed under
CC BY-SA 4.0 as a whole; the code that builds it is MIT. See
[legal/LICENSING.md](../../legal/LICENSING.md#horizon-open-content).
